## 0. 为什么需要这份文档

没有验收标准，就会出现两种情况：
- **永远做不完**（总觉得还能更好）
- **不知道做完了**（做了一堆但说不清进展）

这份文档把"理想态"变成**可测的数字**。

## 2. 每项怎么测

### 2.1 轮廓 IoU（最重要）

**需要**：人工标注的真值多边形。

**做法**：
```python
from xasset.viz import compute_iou

iou = compute_iou(predicted_regions, ground_truth_regions)
avg = sum(iou.values()) / len(iou)
```

**当前障碍**：没有真值标注。

**怎么获得真值**（三种，按成本排序）：
1. **人工在图上描一遍**（最准，但费时）
2. **用 CubiCasa5K 的 SVG 标注**（现成真值，但需下载）
3. **半自动**：用我们的结果打底，人工修正（省力，但有确认偏误）

> **建议**：先用 1~2 张图人工描真值，建立基线。不必多——1 张图的 IoU 就足以判断"是否 0.85 级别"。

### 2.2 region_type 准确率

**需要**：带正确类型标注的真值。

**当前问题**：`StubLabeler` 全部返回 `unknown`，所以准确率必然是 0%。

**测法**：
```
准确率 = 分类正确的区域数 / 总区域数
```

**需要注意**：`unknown` 算不算对？建议**不算**——否则"全部返回 unknown"会得到 0% 但看起来像"没测"。

### 2.3 面积误差

**需要**：真实面积（米制）。

**测法**：
```
相对误差 = |预测面积 - 真实面积| / 真实面积
```

**当前问题**：尺度是用"最大区域的典型面积"反推的，所以**面积误差必然很大**——这个方法本质上就是把某块面积"设成典型值"，其它区域按像素比例换算。

> 这张图有尺寸标注（"BRH 87.50"），如果能识别出这些标注，就能精确知道尺度。这属于"参照物法"的一种。

### 2.4 硬约束通过率

**做法**：把产物过一遍 `understand_hard_constraints()`，统计通过比例。

```python
result = understand_hard_constraints().validate(None, output)
passed = 1.0 if result.ok else 0.0
```

**容易测**——现在就能做，只是还没做。

### 2.5 覆盖率

| 输入类型 | 当前支持 | 需要什么 |
|---------|---------|---------|
| 黑白线条图纸 | ✅ | — |
| 彩色图纸 | 🟡 阈值可能失效 | 更好的二值化 |
| 实景照片 | ❌ | 真实分割模型 |

### 2.6 稳定性（已达标）

**要求**：同一输入跑两次，输出完全一致。

**已有测试保证**：
```python
def test_realize_is_deterministic():
    a = s.realize(ideas, inp, input_kind="drawing")
    b = s.realize(ideas, inp, input_kind="drawing")
    assert a.regions[0].boundary.points == b.regions[0].boundary.points
```

### 2.7 可观测

**已有**：`out/compare.png`（并排对比）、`out/contours.png`、`out/regions.json`

**缺**：指标数字。建议在脚本里加一行输出：
```
IoU: 0.87   硬约束通过: 7/7   耗时: 2.3s
```

### 2.8 性能

**测法**：`time` 整个 `run_understand.py`。

**参考**：当前这张 842×569 的图，纯 Python 连通域标记，预计 1~3 秒。

## 3. 当前基线的诚实说明

**已经确定做到的**：
- ✅ 真实户型图上分出 7 个区域
- ✅ 轮廓目测准确贴合房间
- ✅ 坐标系统正确（多区域相对位置对）
- ✅ 确定性（同输入同输出）
- ✅ 硬约束框架就位

**明确不知道的**：
- ❓ 轮廓 IoU 具体是多少（没真值）
- ❓ 面积误差多大（尺度方法本身不可靠）
- ❓ 硬约束通过率（没测）
- ❓ 换了别的图效果如何（只测了 1 张）

**这个"不知道"的清单本身很重要**——它告诉你下一步该做什么。

## 4. 优先级建议

按"投入产出比"排序：

| 优先级 | 做什么 | 为什么 | 工作量 |
|--------|--------|--------|--------|
| **P0** | 测硬约束通过率 | 零成本，现在就能做 | 小 |
| **P0** | 测端到端耗时 | 零成本 | 小 |
| **P1** | 接 LLM 做语义标注 | 解锁最大的能力缺口 | 中 |
| **P1** | 人工标注 1 张真值，算 IoU | 建立几何基线 | 中 |
| **P2** | 多测几张图（不同风格） | 看泛化性 | 小 |
| **P3** | 引入参照物法改尺度 | 提高面积准确度 | 大 |
| **P4** | 接真实视觉模型 | 支持实景照片 | 大 |

## 6. 什么时候算"understand 做完了"

**所有 P0/P1 项达标**，即：

- [ ] 硬约束通过率 ≥ 95%
- [ ] 端到端耗时 < 5s
- [ ] region_type 准确率 ≥ 80%
- [ ] 轮廓 IoU ≥ 0.85（至少 2 张图）

**P2 以上可以延后**——它们影响的是"适用范围"和"精度上限"，不影响"能不能用"。
