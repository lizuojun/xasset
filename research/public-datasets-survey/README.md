# 公开数据集候选调研 —— 室内 / 城市

**日期**: 2026-09
**状态**: 调研（第一版，部分信息已验证，见每条的"核实"列）
**定位**: **不训练算法**，把公开数据集作为**知识来源**和**测试集**。

**本文档要回答**：
1. 有哪些可用数据集？
2. 它们的标注能转成我们的 `SceneRegion` 契约吗？
3. 许可上能不能用？
4. 优先用哪个？

**关联**：
- `docs/stage-io-contract-spec.md` —— 我们的契约（转换目标）
- `research/foundation-models-multimodal/README.md` —— 大模型能力边界
- `research/scene-recognition-from-raw-input/README.md` —— 输入识别技术路线

---

## 0. 核心判断

> **能拿数据集做的有两件事：① 补充统计先验（面积/尺寸分布）；② 验证识别精度（结构对不对）。**
>
> **不能做的：验证"布局好不好"**——公开数据集没有质量标注。

这个限制必须先认清，否则会高估数据集的价值。

## 1. 室内场景（house）候选数据集

### 1.1 CubiCasa5K ⭐ 首选

| 项 | 内容 |
|----|------|
| 规模 | **5000** 张户型图，**80+** 物体类别 |
| 标注形式 | **SVG 多边形**（dense polygon annotation） |
| 来源 | CubiCasa（芬兰公司） |
| 下载 | Zenodo，直接可下（无需申请） |
| 许可 | ⚠️ **需核实**（原为学术研究用途，商用需确认） |
| 核实 | ✅ 已查 README（2026-09） |

**为什么是首选**：
- **SVG 多边形标注能直接转成我们的 `Polygon` 契约**——这是最关键的匹配点
- 量大（5000），类别细（80+，含门/窗/家具）
- 下载无障碍

**风险**：
- **芬兰户型**，面宽进深习惯与中国不同（房间更方正、少"南北通透"概念）
- 许可需确认能否商用

**可转性**：**高**。SVG → 多边形 → `SceneRegion.boundary`，房间类别 → `region_type`（需词表映射）

### 1.2 RPLAN

| 项 | 内容 |
|----|------|
| 规模 | 约 **8 万** 张室内平面图（论文称 large-scale） |
| 标注形式 | 图像 + 房间类型/边界 |
| 来源 | 中科大 + 酷家乐，SIGGRAPH Asia 2019 |
| 下载 | ⚠️ **需填 Google 表单申请** |
| 许可 | 学术研究用途 |
| 核实 | ✅ 已查项目主页（2026-09） |

**价值**：
- **中国户型**（酷家乐数据）——这是它相对 CubiCasa5K 的最大优势
- 量大，适合统计先验

**风险**：
- 需申请，有等待
- 标注格式需进一步确认（是否直接给多边形坐标）

### 1.3 Structured3D

| 项 | 内容 |
|----|------|
| 规模 | **3500** 套房屋设计（专业设计师制作） |
| 标注形式 | **完整 3D 结构标注**：语义、albedo、深度、法线、布局、floorplan |
| 来源 | 上海科技大学 + 酷家乐，ECCV 2020 |
| 下载 | ⚠️ **需填协议表单申请** |
| 许可 | Structured3D Terms of Use |
| 核实 | ✅ 已查 README（2026-09） |

**独特价值**：
- **有 floorplan 标注 + 3D 结构**——对我们验证 `geometry` 层（轮廓→3D）最有价值
- **中国设计师制作**，户型习惯接近目标市场
- 有 panorama / perspective 图像，可测多模态模型

**风险**：申请流程可能较慢

**可转性**：**高**，特别是对 `geometry` 层的验证

### 1.4 其他值得了解

| 数据集 | 规模 | 特点 | 优先级 |
|--------|------|------|--------|
| **HouseGAN++ / HouseDiffusion** 相关数据 | 数千 | RPLAN 派生，格式规整 | 中（依赖 RPLAN） |
| **FloorPlanCAD** | 万级 | CAD 图纸，含门窗标注 | 中 |
| **Zillow/公开房源数据** | 大 | 只有面积/房间数，无几何 | 低（仅统计用） |

## 2. 城市场景（urban）候选数据集

> 城市场景的需求与室内差别很大：我们要的是**地块/道路/建筑轮廓**，不是房间。

| 数据集 | 规模 | 标注 | 与我们的匹配度 |
|--------|------|------|--------------|
| **OpenStreetMap (OSM)** | 全球 | 建筑轮廓、道路网络、土地利用 | ⭐ **最高**，矢量数据直接可用 |
| **SpaceNet** | 多城市 | 建筑轮廓（卫星图 + 矢量） | 高 |
| **Cityscapes** | 5000 张 | 街景语义分割（像素级） | 中（像素不是矢量） |
| **Inria Aerial** | 360 km² | 建筑物二值掩码 | 中（只有建筑，无道路） |

**结论**：城市场景**OSM 是绝对首选**——它是开放数据、全球覆盖、天然矢量格式（GeoJSON），`Polygon` 直接对齐。

## 3. 可转性评估（最关键的一节）

数据集能不能用，取决于**标注能否转成我们的契约**：

| 数据集 | 轮廓多边形 | 房间类型 | 门窗 | 真实尺寸 | 转 `SceneRegion` |
|--------|-----------|---------|------|---------|-----------------|
| CubiCasa5K | ✅ SVG 多边形 | ✅ 80+类 | ✅ | 🟡 像素坐标，需尺度推断 | **高** |
| RPLAN | ✅ | ✅ | ✅ | ✅ **有真实尺寸** | **高** |
| Structured3D | ✅ | ✅ | ✅ | ✅ 3D 结构 | **高** |
| OSM | ✅ GeoJSON | ✅ 土地利用 | 🟡 部分 | ✅ 真实经纬度 | **高**（城市） |

**关键发现：CubiCasa5K / RPLAN 给的是像素坐标，没有真实米制尺寸。**

这意味着：
- **能验证轮廓形状**（相对关系对不对）
- **不能直接算面积阈值**——必须经过尺度推断

> 而 `data/house/` 的历史数据有真实尺寸，这正是它的不可替代价值。

## 4. 许可与合规注意

| 数据集 | 许可状态 | 商用风险 |
|--------|---------|---------|
| CubiCasa5K | ⚠️ 待核实 | 中（原为研究用途） |
| RPLAN | 学术研究 | 高（明确研究用途，商用需授权） |
| Structured3D | 自定义 Terms | 中（需读协议） |
| OSM | **ODbL**（开放数据许可） | **低**（需署名 + 保持开放） |

**建议**：
- **训练/研究阶段**：都可以用
- **商业产品**：只有 OSM 明确可商用，其余需逐一确认或寻求授权

## 5. 推荐优先级

### 立即可用（无需申请）

| 顺序 | 数据集 | 用途 |
|------|--------|------|
| 1 | **OSM** | 城市地块/道路轮廓，矢量直接对齐 |
| 2 | **CubiCasa5K** | 室内轮廓 + 房间类别，验证识别 |

### 需申请（建议提前启动，因为要等）

| 顺序 | 数据集 | 用途 |
|------|--------|------|
| 3 | **Structured3D** | 最接近中国户型 + 3D 结构，验证 `geometry` |
| 4 | **RPLAN** | 中国户型统计先验 |
